# Solar System in Motion — копія з https://solar-in-motion.vercel.app

Знято 17.10.2026 з продакшн-деплою (Vite-збірка, Three.js).

## Структура
Усі файли лежать у головній папці без підпапок:
- `index.html` — головна сторінка
- `index-*.js` (код застосунку), `three-*.js` (бібліотека Three.js), `index-*.css` (стилі) — зібрані файли
- `2k_*.jpg`, `2k_saturn_ring_alpha.png` — текстури планет (2k)
- `sky.json` — дані зоряної карти
- `favicon.svg`
- `app.pretty.js`, `styles.pretty.css` — відформатовані копії JS і CSS для читання (не підключені до сторінки)

Раніше файли були розкладені по папках `assets/`, `textures/`, `data/`, `readable/` — структуру сплющено, а шляхи в `index.html` та в `index-*.js` (посилання на текстури й `sky.json`) оновлено відповідно.

## Запуск локально
Відкривати через локальний сервер (не file://), наприклад:
    npx serve .
або
    python3 -m http.server 8000

## Важливо
Це зібраний (мініфікований) код. Оригінальних вихідних файлів (src/, окремих модулів, package.json, vite.config) на сайті немає — source maps не опубліковані. Повні вихідники є лише в репозиторії / на машині, де проєкт збирався.
Зовнішні API (NASA APOD, EPIC) викликаються з браузера напряму.
